# AI Agent Instructions

When working in this repository, please start by reading the `index.md` located in the
`docs/` folder to help you understand the overall design, folder structure,
and the core execution patterns of the `runflow` library.

Whenever you make changes to the codebase (especially new features,
architectural shifts, or API updates), update the relevant documentation
in the `docs/` folder to ensure it accurately reflects the latest code changes.
